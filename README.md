## 一、项目介绍

秋绪是一款 **HarmonyOS NEXT 的原生追番客户端**，使用 **ArkTS / ArkUI** 编写
（非套壳、非 WebView 应用），播放内核为 **libmpv**。

它本身**不提供、不存储、不分发任何影视资源**，只是把用户自己添加的番剧站点规则，
聚合成一个统一的界面：一个时间表、一份追番清单、一个播放器，外加弹幕。

- **番剧资料**来自 Bangumi；追番分为在看 / 想看 / 搁置 / 看过 / 抛弃 六类。
- **播放**：用户自行添加规则（兼容社区通用的 Kazumi 规则格式），一次搜索并行查询
  所有来源并按来源分组展示；播放器支持手势调速与亮度音量、长按倍速、
  Anime4K 超分辨率、截图保存到相册、投屏（DLNA）与离线播放。
- **弹幕**：双源设计。**B 站（哔哩哔哩）弹幕已接入并可用**；**弹弹play 是首选来源**
  ——它的弹幕库质量高、对老番与长篇的覆盖通常更准，接入已按官方文档完成，
  待审核通过后生效，届时 B 站转为兜底（详见下一节）。应用内还会用弹幕源的
  分集信息**自动补全每一集的标题**；用户在「弹幕设置」里可以**逐个开关弹幕来源**。
- **隐私**：不需要注册账号、不接入任何行为统计 SDK；播放历史、收藏、规则、
  弹幕缓存全部保存在应用私有目录，卸载即清除。

## 二、弹幕功能：现状与计划

**目前已经完成并且可用：哔哩哔哩（B 站）弹幕。**

- 进入播放页后，应用会按「番剧 → 季 → 分集」自动匹配并加载 B 站弹幕，
  播放时弹幕正常显示（见截图 `2.jpg`），并顺带用它的分集信息**补全每一集的标题**
  （见截图 `3.jpg`：第 1 集「冒险的结束」、第 9 集「断头台阿乌拉」）。

**弹弹play 部分已经按官方文档实现，但目前还取不到数据。**

我们已经在代码里完成了接入所需的一切：

1. **应用凭证鉴权**：签名验证模式 `base64(sha256(AppId + Timestamp + Path + AppSecret))`，
   `Timestamp` 取 UTC 秒、`Path` 为 `/api/v2/...` 且不含查询串；同时实现了凭证模式
   （`X-AppId` + `X-AppSecret`）作为兜底重试。
2. **新版搜索引擎**：按官方 2026-07-13 的改动，搜索接口带上 `?v2=true`；
   并且在「`/api/v2/bangumi/bgmtv/{id}` 映射未命中」时，用剧名搜一次条目兜底。
3. **按《使用约定》做了按需调用与本地缓存**：打开一集才请求一次分集表 + 一次弹幕，
   同一集重进或切回不再重复请求。

但接口目前一律返回 **403**（应用仍在审核中，凭据尚未生效）——所以现阶段弹幕实际由
**B 站**提供，弹弹play 这一路还没有数据。

**本次申请的目的，就是希望能完善弹弹play 部分的功能**：审核通过后把**弹弹play
作为首选弹幕来源**（它的弹幕库质量高、对老番与长篇的覆盖通常更准），
B 站作为兜底；并在此基础上继续跟进官方接口的变化。

应用内「弹幕设置」里三个来源（BiliBili / Gamer / 弹弹play）可**分别开关**
（见截图 `4.jpg`），用户可以随时关闭其中任意一个。

## 三、使用场景

1. **追当季新番**：打开应用先看「本季时间表」，按星期浏览当季番剧；
   点进详情页选择「在看」，之后在「追番」里统一管理。看到哪一集会自动记录，
   下次打开详情页直接「继续观看第 N 集」。
2. **找一部老番或冷门番**：在搜索页输入番名，应用并行查询用户自己添加的所有来源，
   按来源分组展示结果；挑一条线路进入播放页。
3. **边看边看弹幕**：进入播放页后弹幕按集自动加载（目前由 B 站提供；审核通过后
   弹弹play 将作为首选来源）；可调字号 / 不透明度 / 显示区域 / 停留时间，
   可开关顶底滚动、海量弹幕、去重与屏蔽词；弹幕来源同样可以单独关闭。

## 五、弹幕数据的使用方式（对齐《使用约定》）

- 完全免费、无内购无广告；**弹幕功能对所有用户免费开放**，不作为付费点或卖点。
- **只按需调用**：打开一集才请求一次分集表 + 一次弹幕，切集才会再次请求。
- **已做本地缓存**（按官方《缓存建议》）：同一集重进或切回不再重复请求。
- **只读公开接口**：`/api/v2/bangumi/bgmtv/{id}`、`/api/v2/bangumi/{id}`、
  `/api/v2/comment/{episodeId}`、`/api/v2/search/episodes?v2=true`；
  **不调用**发送 / 删除弹幕等写接口，也不申请受限接口。
- 无批量抓取行为（不做「批量下载弹幕」「下载数据库」这类事），单机个人使用，调用频率很低。
- 用户可以逐个关闭弹幕来源。
